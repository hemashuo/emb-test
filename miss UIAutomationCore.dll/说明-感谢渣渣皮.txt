解决Delphi 13编译的程序在XP系统中运行时报错缺少UIAutomationCore.dll文件的问题
Solve the problem of Delphi 13 compiled programs reporting an error of missing UIAutomationCore.dll file when running on XP system

XP 32位:
把XP_x86\UIAutomationCore.dll放进C:\Windows\System32文件夹内
Place XP_x86\UIAutomationCore.dll into the C:\Windows\System32 folder

XP 64位
1.把XP_x64\UIAutomationCore.dll放进C:\Windows\System32文件夹内
Place XP_x64\UIAutomationCore.dll into the C:\Windows\System32 folder

2.把XP_x86\UIAutomationCore.dll放进C:\Windows\SysWoW64文件夹内
Place XP_x86\UIAutomationCore.dll into the C:\Windows\SysWoW64 folder
